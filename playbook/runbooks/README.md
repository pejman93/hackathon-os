# Runbooks

Step-by-step procedures for the repeatable work around an event.

| Runbook | Use it when |
|---|---|
| [New edition](new-edition.md) | You start planning the next event |
| [Emails](emails.md) | You write to participants, mentors, judges, staff or partners |
| [Forms and sheets](forms.md) | You build applications, polls, hand-in or judging |
| [Design](design.md) | You make or change anything visual |
| [Status log](status-log.md) | Something was sent, decided or built |
| [Retro](retro.md) | The event is over and you collect what you learned |
