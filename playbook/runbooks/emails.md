# Emails

Starting points: the [email templates](../email-templates).

## Before writing

- Send official emails to many people from the event mailbox, and personal follow-ups from your own
  account.
- Take addresses from the contact sheet. Never write them into a file.

## The text

- Keep it plain, friendly and short.
- Put dates, time, place, links and deadlines in the text, not only in a picture.
- Don't name a mentor or judge in a participant email, and keep prizes for the day.
- End with "Questions? Just reply to this email." when replies are welcome.

## Recipients

- For many participants, write To yourself and Bcc everyone else, so nobody sees the list.
- If someone else should see it, Cc them and send a separate note with the names by team and no
  addresses, because Bcc stays hidden from Cc.
- For a mail merge, send a test to yourself first and check every field. A merge can drop attachments.

## After

Note it in `STATUS.md`: subject, account, number of recipients, attachments and time.
